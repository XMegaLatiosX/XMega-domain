# My Website

Personal website and portfolio built with React and Supabase.

It works both as a portfolio and as a place where I document my projects, pixel art, game development progress, blog posts and other interests.

## Features

- Blog system
- Project showcase
- Dynamic project progress
- Media uploads (images, audio and video)
- Admin panel
- Authentication
- Responsive interface

## Tech Stack

- React
- Vite
- Tailwind CSS
- Supabase
- React Router

## Why this project?

This website is my main long-term project.

Instead of creating isolated portfolio projects, I continuously expand this application with new features while documenting my work, hobbies and personal projects in one place.
